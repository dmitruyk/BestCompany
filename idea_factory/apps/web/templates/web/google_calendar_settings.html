Setup guide

For you (company owner)

  1. Sign in to Idea Factory with the account that owns your companies.
  2. Open Google Calendar in the top navigation (this page).
  3. Click Connect Google Calendar and approve access for calendar events.
  4. Enable sync and set reminders (for example 60,1440).
  5. Use Sync existing events to push actions that were scheduled before you connected.
  6. Schedule actions on any company calendar — they appear in Google Calendar with reminders.

For administrators (one-time server setup)

  1. Open Google Cloud Console.
  2. Create or select a project → APIs & Services → enable Google Calendar API.
  3. Credentials → Create credentials → OAuth client ID → type Web application.
  4. Add an authorized redirect URI (must match your deploy URL exactly): 
    https://YOUR_HOST/settings/google-calendar/callback/
    For local development, also add: 
    http://127.0.0.1:8000/settings/google-calendar/callback/
  5. Copy the Client ID and Client secret into idea_factory/.env: 
    GOOGLE_CALENDAR_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CALENDAR_CLIENT_SECRET=your-client-secret
GOOGLE_CALENDAR_DEFAULT_REMINDERS=60,1440
  6. Ensure CSRF_TRUSTED_ORIGINS and ALLOWED_HOSTS include your public hostname, then restart the app.
  7. If the app is in Google’s testing mode, add each user’s Gmail under OAuth consent screen → Test users.

Full documentation: idea_factory/docs/google_calendar_integration.md
