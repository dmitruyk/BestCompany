Setup guide

For you (company owner)

  1. Sign in to Idea Factory with the account that owns your companies.
  2. Open Google Calendar in the top navigation (this page).
  3. Click Connect Google Calendar and approve access (you may need to reconnect after a scope update).
  4. A separate {{ portal_calendar_name }} calendar is created in Google — events do not go on your primary calendar.
  5. Enable sync and set reminders (for example 60,1440).
  6. Use Sync existing events to push actions scheduled before you connected.

For administrators (one-time server setup)

  1. Open Google Cloud Console.
  2. Enable Google Calendar API and create an OAuth Web application client.
  3. Redirect URI: https://YOUR_HOST/settings/google-calendar/callback/
  4. Optional in .env: GOOGLE_CALENDAR_PORTAL_NAME=Idea Factory (calendar display name).
  5. Add test users if the OAuth app is in testing mode.

Full documentation: idea_factory/docs/google_calendar_integration.md
