Setup guide

Ollama (local)

  1. Install and run Ollama on the host the app can reach.
  2. Pull a model (e.g. ollama pull llama3.2) and select it above.
  3. Set host URL to your Ollama API (default http://localhost:11434).
  4. Click Test service connection after saving.

OpenAI (cloud)

  1. Add OPENAI_API_KEY to .env and restart the Django process.
  2. Choose a model, save, then run Test service connection.
  3. Individual idea requests can still override provider in the request form.

CLI check: python manage.py check_assistant_llm
